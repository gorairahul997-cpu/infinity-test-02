Overview

Welcome to Infinity Practice

Infinity Practice is an advanced, AI-powered exam preparation dashboard designed to help students prepare for high-stakes exams like JEE, NEET, CBSE Boards, and Foundation Levels (Class 9 & 10). By combining NVIDIA NIM-powered dual-model pipelines (Llama 3.1 8B & 70B) with real-time SQLite pre-warmed caching and an interactive Socratic AI chat tutor, Infinity Practice targets your personal academic weaknesses with zero latency.

Core Modules Breakdown

The application consists of 5 central pages accessible from the dark sidebar menu on the left:

🚀 Live Practice: Custom test session configuration (question formats, counts, timers, subjects, and adaptive difficulty scaling).
📄 PDF Studio: Generation of high-fidelity printable examination sheets with appended solutions.
📊 History: Comprehensive analytics, error logs, scoring history, and exact-question retake options.
📐 Formula Engine: Instant formulas, formulas discoverable by chapter search, and mathematical deep dives.
⚙️ Settings & Info: Local SQLite pre-warm triggers, performance controls, custom academic personalization profile, and themes.

First Session Checklist

1
Select Class & Target Exam

Core Engine

Adaptive Difficulty Mechanics

When difficulty is configured to 🧠 Adaptive, the Live Practice engine evaluates your performance dynamically:

• Correct Streak ≥ 2: Automatically increments difficulty (e.g. from Easy → Medium, or Medium → Hard).
• Incorrect Streak ≥ 2: Automatically decrements difficulty (e.g. Hard → Medium, or Medium → Easy).
• This real-time calibration keeps questions in your zone of proximal development to maximize recall and prevent frustration.

The 7 Question Formats + CS Predict

Infinity supports diverse formats to mirror actual JEE/NEET/Boards structures. Click each format for details:

🔘 Multiple Choice Questions (MCQ) ▼
Single correct option matching. Equations and scientific notations are rendered using KaTeX. Correct responses award +4 points, incorrect responses award -1 (JEE style), and skipped responses award 0 points.
🔢 Numerical / Integer Type ▼
Common in JEE. Requires a direct numeric input (integer or decimal). Renders an input text box rather than choice buttons. Answers are checked to double precision, tolerance margins are applied for rounding based on instructions.
🔄 Assertion-Reason (A-R) ▼
Consists of an Assertion statement and a Reason statement. The options evaluate whether Assertion is True/False, Reason is True/False, and if the Reason is the correct explanation for the Assertion.
✍️ Short Answer / Descriptive ▼
Requires a conceptual explanation typed into a text block. Upon submission, the AI analyzes your response semantically, comparing it to the rubric solution, and scores it from 0 to 10.
📝 Fill in the Blanks ▼
Contains sentences with blank fields. Type the correct term or mathematical expression. Inputs are validated with strict string comparisons, ignoring extra whitespaces and case differences.
🔗 Match the Columns ▼
Displays Column A and Column B containing formulas, properties, or definitions. Select matching coordinates (e.g. A-I, B-III) using the interactive pairing grid.
✅ True / False ▼
Quick binary checks to evaluate fundamental laws, declarations, or formulas. Good for rapid-fire review sessions.
💻 CS-Exclusive: Predict Output ▼
Appears automatically when the subject is set to Computer Science. Renders a block of code (e.g., Python loops, C++ inheritance, SQL queries) formatted inside a code mockup, prompting you to predict the exact standard console output.

Timer & Skip Protocols

Timers are configurable per question (30s, 1m, 2m, 3m, or No Timer). If a question times out, it is auto-marked as Skipped. Skipping a question manually or through timeout resets your streak count to 0, preventing streak point boosts.

PDF Export

Generating Printable Test Papers

PDF Studio transforms your configured session parameters into beautifully formatted, ready-to-print assessment sheets ideal for offline preparation, tests, or classroom worksheets.

Paper Generation Steps

1
Select 'PDF Studio' Tab in Sidebar
The dashboard switches into PDF Studio mode, modifying the theme slightly and preparing the launch buttons.
2
Configure Sheet Settings
Adjust the class, subject, topic, and select which question formats to mix. Set the question slider to your desired volume (e.g. 15 questions).
3
Export & Print
Click 📄 Generate PDF Paper. The app queries the AI or cache database, aggregates the items, and directs you to a preview page. Press Ctrl + P on your keyboard to save as PDF or print. The stylesheet automatically excludes navigation elements.

Layout Structural Specs

Every generated sheet contains: Student Name line, Date line, Max Score indicator, Exam subject title, structured questions with lettered spacing, an answer key table at the end of the question block, and a step-by-step solutions annex starting on a new page.

Formulas

Formula Engine Breakdown

The Formula Engine serves as an interactive reference vault for scientific formulas, laws, and proofs. It renders high-definition LaTeX math equations in real-time.

Chapter Search & Discovery

Type a topic (e.g. Electrostatics, Rotational Motion, Limits & Continuity) in the search box. The database fetches all related equations. Each equation displays with its formula string, standard name, SI units, and application scope.

Interactive Deep Dives

Clicking any formula in the list loads it into the Deep Dive module, or you can write down an equation manually using standard LaTeX. The engine performs a real-time AI breakdown:

• Variables Breakdown: Lists each term, its physical unit, and dimensional formula.
• Derivation Roots: Provides a brief walkthrough of the law or derivation origin.
• Common Traps: Warns about sign conventions, unit scaling, and limits of applicability (e.g., constant acceleration assumption in equations of motion).

Sample Mathematical Render
F = G \frac{m_1 m_2}{r^2} \quad \text{where } G \approx 6.674 \times 10^{-11} \text{ N m}^2/\text{kg}^2
AI Chatbot

Study Buddy Tutoring Modes

The floating chat widget in the bottom-right connects directly to a dual-mode AI pipeline, acting as a personal study assistant during practice.

🧠 Socratic Mode (ON)

The AI will not give you the final answer. Instead, it analyzes your input, asks leading questions, points out minor mathematical or sign errors, and guides you to arrive at the solution on your own. Excellent for deep conceptual learning.

⚡ Direct Mode (OFF)

Acts as a standard assistant. Provides immediate step-by-step proofs, formulas, direct answers, code translations, or conceptual definitions. Best for quick corrections and revisions.

Proactive Toast Notifications

When you fail a question (submit incorrect answer) or skip a question twice in a row, the app triggers a Proactive Help Toast in the bottom-right corner. Clicking the toast opens the chatbot panel, which receives the exact context of the current question. The AI will then suggest a concept check or a step-by-step hint.

Chat Interface Utilities

Maximize your chat flow with these interface features:

⌨️ Keyboard Shortcuts: Press Enter to send a query, and Shift + Enter to insert a line break.
📋 Message Clipboard: Hover over any message sent by the AI and click the quick copy icon to clone the text or code snippet to your clipboard.
💡 Quick Suggestion Chips: Click the suggestions at the bottom (e.g. "Explain like I'm 5") for instant, pre-formatted prompt execution.
Cache Engine

SQLite Cache Engine Mechanics

Live Practice queries a local SQLite database cache pool of pre-warmed questions. When the pool has questions matching your requirements, loading occurs in under 200ms rather than waiting 5-8 seconds for a live model inference.

Cache Warming Controls

In the Caching sub-tab under Settings, you can view the active cache counts for each subject. Click ⚡ Warm [Subject] to queue background generation requests, filling the SQLite tables. You can also wipe the database clean by clicking Clear Cache, which forces 100% live API generation.

Interface Preferences Toggles

Tweak toggles in Settings for direct preference adjustments:

Strict Mode: Disables the explanation drawer until an answer is submitted, preserving active recall conditions.
Performance Mode: Disables screen filters, heavy gradients, dynamic transitions, and slows KaTeX rendering. Optimized for legacy/school systems.
